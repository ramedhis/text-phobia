text-phobia
-----------
 
Letters that flinch from your cursor.
 
Type some text and every letter flees your mouse, then calms
back down once you leave it alone.
 
A small generative type toy -- plain HTML, vanilla JS, and
the Canvas 2D API. One small dependency, gif.js, used only for
GIF export. Also used some well-known fonts.
 
> To use, open [index.html] in a browser.

Notes:
A Tampermonkey userscript version is also available on tampermonkey/
