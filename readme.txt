text-phobia
-----------
 
An experimental typography project exploring the relationship
between text, perception, and visual interaction. Built with
JavaScript and Canvas 2D API.

[Live Demo](https://ramedhis.github.io/text-phobia/)
 
Type some text and every letter flees your mouse, then
calms back down once you leave it alone.

Development:
This project is part of my [creative-coding](https://github.com/ramedhis/creative-coding) collection.
This repository is retained for GitHub Pages deployment.
All future development takes place in the central repository.
